# BoodTube

عميل يوتيوب للجوال مبني بـ Flutter، مستوحى من [SmartTube](https://github.com/yuliskov/SmartTube)
ومصمَّم ليطابق واجهة يوتيوب الرسمية. يستخرج المقاطع على الجهاز مباشرة —
بلا سيرفر وسيط.

---

## المزايا

**التشغيل**
- استخراج على الجهاز عبر `youtube_explode_dart` + InnerTube
- اختيار الجودة حتى 4K، وسرعة تشغيل حتى 3×، وتكبير الفيديو
- البث المباشر عبر HLS
- صورة داخل صورة (أندرويد) والتشغيل في الخلفية
- الترجمات، والفصول، وإيماءات السطوع والصوت
- تعزيز الصوت حتى 300%، ومؤقت النوم، وقائمة التشغيل
- التنزيل للمشاهدة دون اتصال

**الحساب**
- تسجيل دخول بتدفق رمز الجهاز (OAuth Device Flow)
- الرئيسية والاشتراكات وقوائم التشغيل من حسابك
- الإعجاب والاشتراك يُزامَنان مع يوتيوب
- **استكمال المقطع عبر الأجهزة** — ابدأ على الكمبيوتر وأكمل هنا والعكس

**تنقية المحتوى**
- [SponsorBlock](https://sponsor.ajay.app) — تخطي الرعايات والمقدمات بتسع فئات
- [DeArrow](https://dearrow.ajay.app) — عناوين وصور بديلة للمضلِّلة
- [Return YouTube Dislike](https://returnyoutubedislike.com) — إظهار عدد عدم الإعجاب
- إخفاء الشورتس والمقاطع المُشاهَدة والبث المباشر لكل قسم على حدة
- حظر القنوات

**الواجهة**
- ألوان وأبعاد يوتيوب الرسمية، فاتح وداكن
- عربي وإنجليزي بدعم كامل لاتجاه RTL

## أدوات التشخيص

يوتيوب يغيّر سلوكه باستمرار، فهذه الأدوات تقيس ما يفعله *الآن* بدل التخمين:

| الأداة | ماذا تقيس |
|---|---|
| `tool/client_probe.dart` | أي عميل يوتيوب يخدم البث بلا سقف بايتات |
| `tool/range_probe.dart` | أين يتوقف الخادم، وهل السبب صيغة النطاق أم الرابط |
| `tool/live_player_probe.dart` | أي عميل يعطي HLS/DASH لبث مباشر |
| `tool/live_probe.dart` | ما تستطيع مكتبة الاستخراج تقديمه لمقطع بث |
| `tool/poc_check.dart` | فحص سريع لمسار الاستخراج |

## ملاحظات

**غير رسمي.** هذا التطبيق ليس من إنتاج يوتيوب أو جوجل. استخدامه مع حسابك
قد يخالف شروط خدمة يوتيوب، وقد تُقيَّد الحسابات نتيجة ذلك.

**بيانات OAuth.** المعرّفات في `lib/data/youtube/auth/oauth_client.dart` هي
معرّفات تطبيق يوتيوب على التلفزيون المعروفة علناً، وليست أسراراً خاصة —
تُحدِّد *نوع التطبيق* فقط، والتدفق يتطلب موافقتك على google.com في كل حال.

**متجر آبل.** آبل ترفض عملاء يوتيوب غير الرسميين (بند 5.2)، فالتوزيع على
iOS يكون بالتثبيت المباشر لا عبر المتجر.
